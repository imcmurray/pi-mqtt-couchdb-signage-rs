# Fonts

`NotoColorEmoji.ttf`: Noto Color Emoji 2.051 (noto-emoji 2025-08-18, CBDT colour bitmaps),
SIL Open Font License 1.1 (`NotoColorEmoji-OFL.txt`).

- The TVs draw emoji from this file: `pi-slideshow-rs` embeds it at build time (`src/emoji.rs`).
- The manager serves it so the editor preview shows the same emoji the TV will.
